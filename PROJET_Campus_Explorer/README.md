# Projet final : Campus Explorer

Application Android du projet de la mineure, réalisée en binôme (Asma BACHIRBEY et Patrick-Léon GANDONOU).
Elle aide les étudiants à se repérer sur les campus de CY : carte OpenStreetMap (Leaflet.js dans une WebView),
position GPS, suivi d'un trajet par un service au premier plan, lieux enregistrés et historique.

**Code du projet final : https://github.com/Asma-bey/campus-Explorer**
(`main` = version validée, `dev` = nouveautés en attente de validation).
